## 🎯 Objetivos da Disciplina

A disciplina visa fundamentar e consolidar os conceitos essenciais do paradigma de Programação Orientada a Objetos utilizando a linguagem **Java**, abordando tópicos como:

- **Abstração:** Modelagem de entidades do mundo real em classes e objetos.
- **Encapsulamento:** Proteção e controle de acesso a atributos e métodos.
- **Herança e Polimorfismo:** Reutilização de código e flexibilidade de implementação.
- **Entrada e Saída de Dados:** Manipulação de fluxos com a classe `Scanner`.
- **Organização em Pacotes:** Estruturação modular utilizando a instrução `package`.
